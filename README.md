# FísicaLab Virtual Pro (Next.js + TypeScript + Supabase)

Plataforma educativa interactiva con 6 simuladores de física en tiempo real, telemetría en vivo, calculadora paso a paso, modo reto, Tab Bar responsivo, Bottom Sheet de filtros, FAB de creación y Snackbar con función Deshacer.

## Instalación local

```bash
npm install
cp .env.example .env.local
npm run dev
```
